Initialization初期設定

Box Drive integration supports only Windows and macOS. この拡張機能は Windows と macOS のみに対応しています。

These steps are required for the extension to work. これらの手順は、拡張機能を機能させるために必須です。

Prerequisite 前提

Install Python 3. The Python launcher (py) or python.exe on PATH is used. Python 3 をインストール
※ Pythonランチャー (py) か、PATH上の python.exe を使います

/usr/bin/python3 is used. If macOS asks to install the command line developer tools on first use, install them. /usr/bin/python3 を使います。初回にコマンドライン・デベロッパ・ツールのインストールを求められた場合はインストールしてください

1. Setup 1. 設定

Download and extract the following file, then run setup.bat. 以下のファイルをダウンロード・展開してから setup.bat を実行 Download and extract the following file, then run sh setup.sh in Terminal. 以下のファイルをダウンロード・展開してから、ターミナルで sh setup.sh を実行

  • nativehost-setup.zip

2. Confirm the setup 2. 動作確認

  1. Path to a folder or file to open in Explorer Explorerで開く フォルダ／ファイル のパス

Usage 使い方

On a Box folder or file page, click the extension icon to open the corresponding Box Drive folder in Explorer. Boxのフォルダあるいはファイルのページを開いている状態で、 この拡張機能のアイコン をクリックすると、 該当する Box DriveのフォルダがExplorerで開きます。

Extras 以下おまけ
  • It also works on file: pages, such as file:スキームのページでも同様に動作します
    • file://C:/ProgramData/
  • Right-click a file: link like the one above to open it in Explorer. 上のようなfile:リンクを右クリックすることでExplorerを開けます
  • Select a path such as C:\ProgramData\ and right-click to open it in Explorer. C:\ProgramData\ のようなファイルパス文字列を範囲選択して右クリックしてもExplorerを開けます
