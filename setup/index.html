    Helperヘルパー

    The extension needs a small helper program on this computer to open folders in . フォルダを で開くために、小さなヘルパープログラムをこのパソコンに入れます。

    The helper is registered for another extension ID. This happens after reinstalling the extension or loading it from another folder. ヘルパーが別の拡張機能 ID 向けに登録されています。拡張機能を入れ直したときや、別のフォルダから読み込んだときに起こります。

    The helper is registered but couldn't start. Python may be unavailable, or the helper may be too old. ヘルパーは登録されていますが、起動できませんでした。Python が使えないか、ヘルパーが古い可能性があります。

    Versionバージョン

    1. Python 3 is required. The installer from python.org sets it up as the helper needs. Python 3 が必要です。python.org のインストーラーで入れれば、そのまま使えます。
    3. Extract nativehost-setup.zip and double-click setup.bat in it. If Windows shows "Windows protected your PC", choose "More info" and then "Run anyway". nativehost-setup.zip を展開して、中の setup.bat をダブルクリックします。 「Windows によって PC が保護されました」と表示されたら、「詳細情報」→「実行」を選びます。
    4. Open Terminal, type sh and a space, drag the downloaded open-box-drive-setup.sh into the window, and press Return. ターミナルを開き、sh と半角スペースを入力してから、ダウンロードした open-box-drive-setup.sh をウインドウにドラッグして Return キーを押します。

      Or runまたは次のコマンドを実行: sh ~/Downloads/open-box-drive-setup.sh

      If macOS asks to install the command line developer tools, install them: the helper uses /usr/bin/python3. コマンドライン・デベロッパ・ツールのインストールを求められたら、インストールしてください（ヘルパーは /usr/bin/python3 を使います）。

    Waiting for the helper. This page moves on by itself when the setup finishes. ヘルパーを待っています。セットアップが終わると、この画面は自動で次に進みます。
